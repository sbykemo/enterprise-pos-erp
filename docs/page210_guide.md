# 📦 دليل شاشة إدارة الأصناف - Page 210 (Item Master)

> شرح شامل للبنية والمكونات ودليل الاختبار الكامل

---

## 🗺️ ما هي شاشة Item Master؟

شاشة Item Master هي **قلب إدارة المنتجات** في أي نظام ERP/POS احترافي.
كل صنف تبيعه في Page 100 (الكاشير) **يجب أن يُسجَّل أولاً هنا** قبل أن يظهر في شاشة البيع.

---

## 🏗️ بنية الشاشة (3 طبقات رئيسية)

```
┌─────────────────────────────────────────────────────────────┐
│  🔍 شريط الفلاتر (Search & Filter Bar)                      │
│  [بحث نصي] [فئة] [نوع الصنف] [حالة: نشط/متوقف]           │
├─────────────────────────────────────────────────────────────┤
│  📦 جريد الأصناف الرئيسي (Item Master Interactive Grid)     │
│  ┌──────┬──────────┬──────┬───────┬──────┬──────────────┐  │
│  │ كود  │ اسم عربي│ فئة  │ نوع  │ سعر  │ إجراءات      │  │
│  ├──────┼──────────┼──────┼───────┼──────┼──────────────┤  │
│  │ IT01 │ قهوة     │ مشرب │PRODUCT│ 16  │ 🎨متغيرات 🏪 │  │
│  │ IT02 │ قميص     │ ملابس│PRODUCT│ 89  │ 🎨متغيرات 🏪 │  │
│  └──────┴──────────┴──────┴───────┴──────┴──────────────┘  │
│  [✚ إضافة صنف] [💾 حفظ] [🗑️ حذف]                          │
├─────────────────────────────────────────────────────────────┤
│  🎨 جريد المتغيرات (Variants Grid) - يظهر عند الضغط على    │
│  زر "🎨 متغيرات" لأي صنف                                   │
│  [SKU Code] [باركود] [سعر التكلفة] [المخزون] [حالة]        │
└─────────────────────────────────────────────────────────────┘
```

---

## 📖 شرح كل حقل في الجريد الرئيسي

| الحقل | الشرح | مثال |
|---|---|---|
| **ITEM_CODE** | كود فريد لكل صنف (لا يتكرر) | `COFFEE-LATTE-001` |
| **ITEM_NAME_AR** | اسم الصنف بالعربية (يظهر في الكاشير) | `كافيه لاتيه كلاسيك` |
| **ITEM_NAME_EN** | اسم الصنف بالإنجليزية | `Classic Cafe Latte` |
| **CATEGORY_ID** | الفئة التي ينتمي إليها الصنف | `مشروبات ساخنة` |
| **ITEM_TYPE** | نوع الصنف: | |
| | `PRODUCT` = منتج مادي له مخزون | قميص، قهوة |
| | `SERVICE` = خدمة بدون مخزون | شحن، تركيب |
| | `BUNDLE` = باقة من عدة منتجات | وجبة كاملة |
| | `COMPONENT` = مكوّن يدخل في باقة | خس، طماطم |
| **SECTOR_TYPE** | قطاع العمل: `RETAIL`/`FNB`/`SERVICE`/`ALL` | |
| **PRIMARY_UOM_CODE** | وحدة القياس الأساسية | `EA` = قطعة، `KG` = كيلو |
| **BARCODE** | الباركود الرئيسي للمسح الضوئي | `6281234567890` |
| **MIN_SALE_PRICE** | أدنى سعر مسموح به (يمنع البيع بأقل منه) | `10.00` |
| **COST_PRICE** | سعر التكلفة (لحساب هامش الربح) | `8.00` |
| **IS_TAXABLE** | هل خاضع للضريبة؟ `Y`/`N` | `Y` |
| **IS_ACTIVE** | هل الصنف نشط ويظهر في الكاشير؟ `Y`/`N` | `Y` |
| **VARIANT_COUNT** | عدد المتغيرات (مقاسات/ألوان) | `3` |
| **TOTAL_STOCK** | إجمالي المخزون في جميع الفروع | `150` |

## 🎨 ما هي المتغيرات (Variants)؟

> **الفكرة:** القميص هو **صنف واحد** (Item)، لكن له **3 مقاسات** (S، M، L) - كل مقاس هو **متغير (Variant)**.

```
┌─────────────────────────────────────────────────────────┐
│ ITEM: قميص بولو قطني كلاسيك (ITEM_ID: 1000002)        │
│                                                         │
│  ├── VARIANT: قميص-صغير  (SKU: SHIRT-POLO-S)           │
│  │    Barcode: 6281234000001  |  Stock: 30              │
│  │                                                      │
│  ├── VARIANT: قميص-وسط   (SKU: SHIRT-POLO-M)           │
│  │    Barcode: 6281234000002  |  Stock: 50              │
│  │                                                      │
│  └── VARIANT: قميص-كبير  (SKU: SHIRT-POLO-L)           │
│       Barcode: 6281234000003  |  Stock: 20              │
└─────────────────────────────────────────────────────────┘
```

## 🧪 دليل الاختبار الكامل (Test Plan)

---

### ✅ اختبار 1: إضافة صنف جديد بسيط بدون متغيرات

**الهدف:** التأكد من إضافة صنف جديد وظهوره في شاشة الكاشير.

**الخطوات:**
1. في الجريد الرئيسي، اضغط **✚ إضافة صنف** (Add Row).
2. أدخل البيانات التالية:
   - `ITEM_CODE` = `TEST-ITEM-001`
   - `ITEM_NAME_AR` = `صنف تجريبي`
   - `ITEM_NAME_EN` = `Test Item`
   - `CATEGORY_ID` = اختر أي فئة موجودة
   - `ITEM_TYPE` = `PRODUCT`
   - `SECTOR_TYPE` = `RETAIL`
   - `PRIMARY_UOM_CODE` = `EA`
   - `BARCODE` = `9999999999999`
   - `MIN_SALE_PRICE` = `50`
   - `COST_PRICE` = `35`
   - `IS_TAXABLE` = `Y`
   - `IS_ACTIVE` = `Y`
3. اضغط **💾 حفظ (Save)**.

**النتيجة المتوقعة:**
- ✔️ الصنف يظهر في الجريد.
- ✔️ عند فتح Page 100 (الكاشير)، يظهر "صنف تجريبي" في الكروت.
- ✔️ عند مسح باركود `9999999999999`، يُضاف الصنف للسلة بكمية 1.

---

### ✅ اختبار 2: فحص منع تكرار الباركود

**الهدف:** التأكد من رفض النظام لباركود مسجل مسبقاً.

**الخطوات:**
1. أضف صنفاً جديداً وأدخل باركود `9999999999999` (نفس الاختبار السابق).
2. اضغط **💾 حفظ**.

**النتيجة المتوقعة:**
- ✔️ تظهر رسالة خطأ حمراء: `هذا الباركود مسجل لصنف آخر بالفعل!`
- ✔️ لا يُحفظ الصنف.

---

### ✅ اختبار 3: فلاتر البحث

**الهدف:** التأكد من عمل فلاتر البحث بشكل صحيح.

**الخطوات:**
1. في حقل **🔍 بحث**، اكتب `كافيه` ← يجب أن يظهر صنف القهوة فقط.
2. امسح البحث، ثم اختر من **الفئة** أي فئة محددة ← يجب أن تظهر أصناف هذه الفئة فقط.
3. اختر **الحالة = غير نشط** ← يجب أن تظهر الأصناف المتوقفة فقط.
4. اختر **الحالة = جميع الحالات** ← يجب أن تظهر جميع الأصناف.

**النتيجة المتوقعة:**
- ✔️ الجريد يتحدث فورياً عند تغيير أي فلتر بدون الحاجة لضغط زر.

---

### ✅ اختبار 4: إدارة المتغيرات (Variants)

**الهدف:** التأكد من إضافة وتعديل المتغيرات لصنف موجود.

**الخطوات:**
1. ابحث عن صنف `قميص بولو قطني كلاسيك`.
2. اضغط زر **🎨 متغيرات (3)**.
3. ستنزل الصفحة لجريد المتغيرات.
4. تحقق من ظهور المتغيرات الثلاثة (S، M، L).
5. اضغط **✚ إضافة** وأضف متغيراً جديداً:
   - `SKU_CODE` = `SHIRT-POLO-XL`
   - `BARCODE` = `6281234000004`
   - `COST_PRICE` = `60`
   - `IS_ACTIVE` = `Y`
6. اضغط **💾 حفظ**.

**النتيجة المتوقعة:**
- ✔️ يظهر المتغير الجديد في الجريد.
- ✔️ رقم المتغيرات في زر الصنف الرئيسي يتحدث من `3` ← `4`.

---

### ✅ اختبار 5: تعطيل صنف (Deactivate)

**الهدف:** التأكد من اختفاء الصنف المتوقف من شاشة الكاشير.

**الخطوات:**
1. اختر **صنف تجريبي** وغيّر `IS_ACTIVE` من `Y` إلى `N`.
2. اضغط **💾 حفظ**.
3. افتح Page 100 (الكاشير).

**النتيجة المتوقعة:**
- ✔️ "صنف تجريبي" **لا يظهر** في كروت المنتجات في الكاشير.
- ✔️ مسح باركود `9999999999999` يُظهر رسالة `⚠️ الصنف غير موجود أو غير نشط!`.

---

### ✅ اختبار 6: تعديل السعر وأثره الفوري على الكاشير

**الهدف:** التأكد من تأثير تغيير السعر فوراً على شاشة البيع.

**الخطوات:**
1. غيّر `MIN_SALE_PRICE` لصنف القهوة من `16` إلى `20`.
2. اضغط **💾 حفظ**.
3. افتح Page 100 (الكاشير).

**النتيجة المتوقعة:**
- ✔️ يظهر سعر القهوة `20.00` في كارت المنتج.
- ✔️ عند إضافة القهوة للسلة، يُحسب السعر بـ `20`.

---

## ⚠️ أشياء يجب الانتباه إليها

> [!IMPORTANT]
> - **ITEM_CODE** يجب أن يكون فريداً ويُفضل أن يتبع نظاماً منطقياً: `[فئة]-[اسم]-[رقم]`
> - **BARCODE** يجب أن يكون مسجلاً بالضبط كما هو مطبوع على المنتج
> - الصنف الذي له `HAS_VARIANTS = Y` لا يُمكن بيعه مباشرة في الكاشير إلا باختيار متغير محدد

> [!WARNING]
> - لا تحذف صنفاً إذا كان له فواتير مسجلة (Order Lines) ← سيُعطي خطأ FK Constraint
> - بدلاً من الحذف، غيّر `IS_ACTIVE` إلى `N` لإخفائه من البيع مع الاحتفاظ بالسجل التاريخي
